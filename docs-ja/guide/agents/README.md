# エージェント詳細解説

ドメインエージェントごとに1ページを割き、その担当ドメイン、主導および支援するステージ、読み込む知識、そして協働のしかたを解説します。全14エージェントの構成は、11のドメインエージェント、2つのレビュー専用エージェント、そして適応型ワークフローのコンポーザーからなります。この索引では、ステージ作業を実行する11のドメインエージェントを扱います。

レビュー専用エージェントは、プロダクトとアーキテクチャの独立したチェックを担います。コンポーザーは適応型のステージ計画を提案し、再構成します。3つの役割グループすべてと、30の狭いエージェントではなく11の広いドメインエージェントを採用した思想については、[エージェントの章](../06-agents.md)を参照してください。フロントマターの契約、ツール許可リスト、完全な比較マトリクスについては、開発者リファレンスの[エージェントリファレンス](../../reference/agents/README.md)を参照してください。
