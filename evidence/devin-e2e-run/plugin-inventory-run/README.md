Validation of Rubén's patch 0003 ("plugin sync refuses on Devin: the Devin
plugin projection ships only `.devin-plugin/plugin.json`, but inventory
discovery resolves the harness as `claude` and looks for

landed on top of it as `3cf198e2`. Read `SUMMARY.md` for the verdict, root

## Commands

Steps 1–3 are plain tool/test runs in the temp build root. Only the typecheck and lint command lines were recorded in their captures; the others below are the equivalent forms (step 6 used the same ones):

```bash
bun test tests/unit/t242-plugin-state.test.ts                 # step1 (before) / step3 (after)
tsc --noEmit -p tsconfig.json && tsc --noEmit -p tsconfig.tests.json && tsc --noEmit -p tsconfig.adapters.json
biome check --error-on-warnings core harness scripts plugins tests
bun scripts/package.ts && bun scripts/package.ts --check
bash tests/run-tests.sh --integration --filter t188-plugin-compose
bash tests/run-tests.sh --integration --filter 'plugins/test-pro|plugin\.test'
bun inventory-repro.ts [.devin]                               # quick discoverPluginInventory probe
```

Step 4 is the scripted end-to-end driver:

```bash
bash step4-run.sh <build-root> before   # <build-root> = the live checkout (dafdaa99, no patch)
bash step4-run.sh /tmp/aidlc-devin-patch after
```

- **Part A** copies `<build-root>/dist/devin/` into a scratch project and
  exports the Devin SessionStart hook env (`CLAUDE_PLUGIN_ROOT=<build-root>/dist/plugins/test-pro/devin`,
  `CLAUDE_PROJECT_DIR`, `DEVIN_PROJECT_DIR`, `AIDLC_HARNESS_DIR=.devin`,
  `AIDLC_HARNESS_NAME=devin`, `AIDLC_CLAUDE_PLUGIN_REGISTRY=/nonexistent`),
  then runs A1 `aidlc-plugin.ts sync --json`, A2 `aidlc-plugin.ts list --json`,
  A3 `aidlc.ts engine plugin list --json`, A4 `aidlc.ts doctor --json`, and
  A5 lists the compose stamp, retry markers/drops, and composed plugin stages.
- **Part B** runs the vendored `hooks/compose.ts` directly under bun with
  `PLUGIN_ROOT` set by hand and every other root alias unset — the portable
  fallback path that bypasses `aidlc-plugin.ts` inventory entirely.
