### Retained-artifact policy

- **Commit:** deterministic fixtures containing only the fields tests consume; compact provenance (build, date, capture method, sanitization, case mapping, limits); result/limits tables; rerun recipes.
- **Do not commit:** full ATIF session exports, session databases or WAL/SHM excerpts, generated audit or state trees, host logs, hook-health directories, filesystem snapshots, complete vendor/system prompts, unredacted identifiers or local paths, or exploratory transcripts.
- **External artifacts:** optional and owner-controlled only — record a checksum and the approved private location; a public PR comment or repository branch is not an archive.
- **History caveat:** deleting a path removes it from the tracked tree; it does not purge the blobs from earlier commits. Full-history sanitation is a separate, explicitly approved operation.
- **Grandfathered exception:** the four latest attended-run directories under `evidence/devin-e2e-run/` (`session-isolation-run/`, `native-dispatch-run/`, `background-lifecycle-run/`, `reviewer-scope-run/`) were explicitly retained by the owner after the Item 9 reduction. This exception is inventoried here with provenance and limits; it grants no permission to add another raw export, snapshot, or run tree — any new raw evidence requires a new owner decision. One such decision was taken on 2026-09-22 for `final-revalidation-run/` (text-only tier captures, harness logs, and GitHub state for the `2b6ea4b6` revalidation — no session exports, databases, or snapshots); it is inventoried in the table above under the same rules.

**Native dispatch acceptance protocol** (executed 2026-09-17/18; result row and retained artifacts at `evidence/devin-e2e-run/native-dispatch-run/` above): on a fresh project installed from the rebuilt `dist/devin`, run the express `hello.py` workflow to Plan Approval and approve through the native prompt.
