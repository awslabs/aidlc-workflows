# 비전 문서: CalcEngine 과학 계산기 API

## Executive Summary

CalcEngine은 REST API로 제공되는 호스팅형 과학 계산 라이브러리로, 소프트웨어 개발팀이 직접 계산 로직을 구축·유지하지 않고도 정확하고 표준을 준수하는 수학 계산을 자사 애플리케이션에 내장할 수 있게 합니다. 핵심 제품과 무관한 수학 함수를 구현·테스트·디버깅하는 데 수 개월을 쓰는 엔지니어링 팀의 반복 문제를 해결합니다. 24개월 내 ARR $2M을 창출하는 구독형 API 서비스를 통해, 에듀테크·금융 모델링·엔지니어링 시뮬레이션·데이터 분석 분야의 개발자를 확보하는 것이 목표입니다.

## Business Context

### 문제 정의 (Problem Statement)

교육, 금융, 엔지니어링, 과학 분야의 소프트웨어 팀들은 기본 산술을 넘어선 수학 계산을 정기적으로 필요로 합니다. 선택지는 둘 중 하나입니다 — 로컬 라이브러리를 쓰거나(언어별, 플랫폼 간 일관성 없음, 유지보수 부담) 직접 수학 함수를 구현하는 것(비용·오류·시간 모두 큼).

구체적인 문제:

- **정확성 위험**: 수학 전문성이 없는 팀들은 미세한 부동소수점 오류, 잘못된 엣지 케이스 처리(0 나누기, 오버플로, 도메인 오류), 일관되지 않은 반올림을 도입하여 제품의 신뢰를 잃습니다.
- **중복 노력**: 삼각 함수, 통계 분포, 행렬 연산, 단위 변환이 필요한 모든 팀이 독립적으로 구현합니다. 이 작업이 수천 개 회사에서 반복됩니다.
- **플랫폼 간 불일치**: Python 백엔드의 계산 결과가 JavaScript 프런트엔드의 동일 계산 결과와 다를 수 있습니다. 여러 플랫폼을 운영하는 고객은 일관성을 보장할 수 없습니다.
- **컴플라이언스/감사 가능성**: 규제 산업(금융, 의료, 엔지니어링)에서는 계산이 추적·버전 관리·검증 가능해야 합니다. 임시 구현은 감사 요건을 거의 충족하지 못합니다.

### 비즈니스 동인 (Business Drivers)

- **API 우선 경제**: 개발자들은 라이브러리를 임베드하기보다 호스팅 API를 소비하는 것을 선호하는 추세입니다. Stripe(결제), Twilio(통신), SendGrid(이메일)가 이 모델을 입증했습니다. 수학 계산에는 그에 상응하는 서비스가 없습니다.
- **에듀테크 성장**: 글로벌 교육 기술 시장이 빠르게 확장 중이며, 계산기 기능은 수학·과학·공학 콘텐츠 전반의 보편적 요구사항입니다.
- **규제 압력**: 금융 서비스 회사는 계산 정확성에 대한 감독이 강화되고 있습니다. 인증되고 감사 가능한 API는 컴플라이언스 부담을 줄여줍니다.
- **AI/ML 전처리**: 데이터 사이언스 팀은 모델 학습 전 전처리 단계로 신뢰할 수 있는 수학 변환이 필요합니다. 정밀도와 재현성을 보장하는 API는 ML 파이프라인에서 명확한 가치를 가집니다.

### 비즈니스 제약 (Business Constraints)

- **부트스트랩 예산**: 초기 개발은 기존 매출에서 자체 자금 조달. MVP 단계에서는 외부 투자 계획 없음. 총 MVP 예산은 $150K (개발, 인프라, 초기 마케팅 포함).
- **소규모 팀**: 백엔드 개발자 2명, 프런트엔드 개발자 1명(문서 포털 용), QA 엔지니어 1명. MVP 단계에서 전담 수학 박사 부재.
- **출시 일정**: Phase 2 투자 결정 이전 수요 검증을 위해 MVP는 6개월 내 공개되어야 함.

- **정확성 표준**: 모든 함수는 IEEE 754 배정도 산술 이상의 정확성을 가져야 함. 임의 정밀도 모드는 Phase 2 기능이며 MVP 아님.

## Full Scope Vision (전체 비전)

### Product Vision Statement

CalcEngine은 기본 산술을 넘어서는 수학 연산이 필요한 모든 애플리케이션의 기본 계산 레이어가 됩니다 — 마치 Stripe가 결제의 기본 레이어가 된 것과 같이. 직접 구현하는 것보다 더 정확하고 일관되며 통합이 쉬운 API를 제공함으로써 이를 달성합니다.

### Feature Areas

#### Feature Area 1: 핵심 산술 및 대수 (Core Arithmetic and Algebra)

- **설명**: 표준 언어 수학 라이브러리가 안정적으로 제공하지 못하는 기본 수학 연산.
- **주요 기능**:
  - 임의 정밀도 정수·소수 산술 (최대 1,000자리까지 설정 가능)
  - 표현식 파싱·평가 ("2 * sin(pi/4) + log(100)" 같은 문자열 표현식 수용)
  - 다항식 연산 (평가, 근 찾기, 인수분해)
  - 방정식 풀이 (1차, 2차, 3차, 선형 방정식계)
  - 분수/유리수 산술 (정확한 표현, 약분)
  - 복소수 산술 (덧셈, 곱셈, 극형식/직교형식 변환)
- **사용자 가치**: 개발자가 수학 표현식을 문자열로 보내고 검증된 정밀 결과를 받습니다. 파서 구현, 연산자 우선순위, 부동소수점 드리프트, 엣지 케이스 걱정이 없습니다.

#### Feature Area 2: 삼각법 및 기하 (Trigonometry and Geometry)

- **설명**: 완전한 삼각·기하 계산.
- **주요 기능**:
  - 6개의 삼각 함수와 역함수 (sin, cos, tan, csc, sec, cot)
  - 쌍곡선 함수와 역함수
  - 도/라디안/그라디안 변환
  - 좌표계 변환 (직교, 극, 구면, 원통)
  - 표준 도형의 기하 계산 (넓이, 부피, 둘레)
  - 2D/3D 공간의 거리/각도 계산
- **사용자 가치**: 특수각의 정확값, 사분면 처리, 도메인 검증 같은 삼각함수 엣지 케이스 구현 필요 제거.

#### Feature Area 3: 통계 및 확률 (Statistics and Probability)

- **설명**: 통계 분석 및 확률 분포 함수.
- **주요 기능**:
  - 기술 통계 (평균, 중앙값, 최빈값, 분산, 표준편차, 사분위수, 백분위수)
  - 확률 분포 (정규, 이항, 푸아송, 카이제곱, t, F) — PDF, CDF, 역 CDF
  - 회귀 분석 (선형, 다항, 지수, 로그)
  - 가설 검정 (t-test, 카이제곱, ANOVA)
  - 조합론 (순열, 조합, 팩토리얼, 이항 계수)
  - 분포·시드 설정이 가능한 난수 생성
- **사용자 가치**: 한 번의 API 호출이 통계 라이브러리 임포트와 설정을 대체합니다. 결과는 재현 가능하고 감사 가능합니다.

#### Feature Area 4: 선형대수 및 행렬 연산 (Linear Algebra and Matrix Operations)

- **설명**: 엔지니어링·그래픽·데이터 사이언스를 위한 행렬·벡터 계산.
- **주요 기능**:
  - 행렬 산술 (덧셈, 곱셈, 스칼라 연산)
  - 행렬 분해 (LU, QR, SVD, Cholesky, 고유값)
  - 행렬식, 역행렬, 랭크, 트레이스
  - 벡터 연산 (내적, 외적, 정규화)
  - 선형 방정식계 (가우스 소거, 최소제곱)
  - 대규모 문제를 위한 희소 행렬 지원
- **사용자 가치**: 시뮬레이션·ML·그래픽 애플리케이션 팀이 LAPACK 링킹이나 네이티브 바인딩 유지보수 없이 검증된 선형대수를 사용.

#### Feature Area 5: 미적분 (Calculus)

- **설명**: 기호적·수치적 미적분 연산.
- **주요 기능**:
  - 수치 미분 (1차 및 고차 도함수)
  - 수치 적분 (사다리꼴, 심슨, 가우스 구적법 등 정적분)
  - 기호 미분/적분 (지원되는 표현식 유형)
  - 극한과 급수 전개 (테일러, 매클로린)
  - 상미분 방정식 풀이 (오일러, 룽게-쿠타)
- **사용자 가치**: 컴퓨터 대수 시스템 임베딩 없이 미적분 연산을 API로 사용.

#### Feature Area 6: 단위 변환 및 물리 상수 (Unit Conversion and Physical Constants)

- **설명**: 표준 단위 변환과 검증된 물리·수학 상수 접근.
- **주요 기능**:
  - 모든 SI 단위와 일반 야드파운드 단위 변환 (길이, 질량, 온도, 시간, 에너지, 압력, 속도 등)
  - 통화 변환 (금융 데이터 공급자의 일일 환율 업데이트)
  - 물리 상수(광속, 플랑크 상수, 아보가드로 수 등) — 출처와 불확실도 포함
  - 임의 정밀도의 수학 상수(pi, e, 황금비 등)
  - 차원 분석 (단위 조합이 물리적으로 의미 있는지 검증)
- **사용자 가치**: 여러 변환 라이브러리와 하드코딩된 상수를 단일 API로 대체, 출처 및 최신성 보장.

#### Feature Area 7: 금융 수학 (Financial Mathematics)

- **설명**: 대출·투자·리스크 분석을 위한 금융 계산 함수.
- **주요 기능**:
  - 화폐의 시간가치 (현재가치, 미래가치, 연금, 영구연금)
  - 대출 상환 일정
  - 채권 가격·수익률 계산
  - 옵션 가격 (Black-Scholes, 이항 모델)
  - IRR, NPV
  - 감가상각 (정액, 정률, 연수합계)
- **사용자 가치**: FinTech 회사가 자체 수학 엔진 구축 없이 감사 가능한 규제 준수 계산을 사용.

#### Feature Area 8: 개발자 경험 및 플랫폼 (Developer Experience and Platform)

- **설명**: CalcEngine 채택을 쉽게 만드는 API 플랫폼, 문서, SDK, 개발자 도구.
- **주요 기능**:
  - 라이브 "try it" 샌드박스가 포함된 인터랙티브 API 문서
  - Python, JavaScript/TypeScript, Java, C#, Go, Ruby 용 클라이언트 SDK
  - 장시간 계산(배치 처리)을 위한 웹훅 지원
  - API 키별 계산 이력 및 감사 로그
  - 명확한 할당량과 초과 처리가 있는 레이트 리밋
  - 12개월 폐기 정책의 API 버전 관리
  - 팀용 워크스페이스 (공유 API 키, 사용량 대시보드, 청구 관리)
- **사용자 가치**: 가입부터 첫 성공적 API 호출까지 5분 미만.

### 통합 지점 (Integration Points)

- **결제 처리(Stripe)** - 구독 청구 및 사용량 기반 미터링
- **신원 공급자(Auth0 또는 Cognito)** - 개발자 계정 인증
- **금융 데이터 공급자**(환율) - 일일 환율 피드
- **NIST / CODATA** - 물리 상수의 신뢰 출처
- **CI/CD 시스템**(GitHub Actions, GitLab CI) - SDK 게시 및 버전 관리
- **모니터링**(Datadog 또는 CloudWatch) - API 성능, 오류율, 사용량 대시보드

### 사용자 여정 (Full Vision)

#### Journey 1: EdTech 개발자가 강좌 플랫폼에 계산 기능 추가

1. 개발자가 "scientific calculator API"를 검색해 CalcEngine 문서를 발견.
2. 무료 계정을 만들고 2분 내 API 키 발급.
3. 인터랙티브 문서를 둘러보고 trigonometry 엔드포인트를 찾아 샌드박스에서 `sin(pi/4)` 시연.
4. pip로 Python SDK 설치 후, 학생 입력 표현식을 CalcEngine에 보내고 결과를 표시하는 3줄 통합 작성.
5. 학생이 답이 어떻게 도출되었는지 볼 수 있도록 단계별 풀이를 반환하도록 API 구성.
6. 강좌 플랫폼 가동. 매일 수천 명의 학생이 계산을 제출. 무료 등급 한도에 도달하면 유료 등급으로 업그레이드.

**Outcome**: 교육 플랫폼이 수 주를 들여 수학 파싱을 만들 필요 없이 한 오후 만에 안정적인 계산기 기능을 출시.

#### Journey 2: FinTech 스타트업의 대출 비교 도구 구축

1. 대출 스타트업의 제품팀이 고객 대상 대출 비교 도구를 위해 상환 일정, APR 계산, 현재가치 계산 필요.
2. 개발자가 CalcEngine 가입 후 Financial Mathematics 섹션으로 이동.
3. loan amortization 엔드포인트로 30년 6.5% 모기지의 상환 일정 생성. 월별 원금/이자/잔액 결과를 받음.
4. NPV·IRR 엔드포인트를 통합해 고객이 여러 대출 제안을 나란히 비교 가능.
5. 컴플라이언스 팀이 CalcEngine의 정확성 인증과 감사 로그 검토. 각 계산은 타임스탬프가 찍힌 입력/출력과 버전이 있는 API 호출까지 추적 가능.

**Outcome**: 자체 계산 로직 구축 없이 컴플라이언스 가능한 감사 가능 금융 도구 출시.

#### Journey 3: 데이터 사이언티스트가 ML 파이프라인에서 CalcEngine 사용

1. 의료 회사의 데이터 사이언티스트가 모델 학습 전 환자 측정 데이터를 통계 변환(z-점수, 백분위 순위, 로그 변환)으로 정규화해야 함.
2. CalcEngine Python SDK 설치 후 Jupyter 노트북에서 통계 엔드포인트 호출.
3. SDK가 값 배열을 받아 기술 통계와 변환된 데이터셋을 반환.

5. CalcEngine은 재현 가능한 결과(동일 입력에 대해 버전을 통틀어 동일 출력)를 보장하므로, 사이언티스트는 논문에서 재현성을 위해 API 버전을 인용할 수 있음.

**Outcome**: 사용자 정의 통계 코드를 작성·디버그하지 않고도 검증되고 재현 가능한 통계 변환 사용.

## MVP Scope

### MVP 목표 (MVP Objective)

핵심 수학 함수로 출시하여 무료 등급 가입을 통해 채택을 검증하고, 출시 후 6개월 내 최소 50개 계정을 유료로 전환함으로써 개발자가 호스팅형 과학 계산기 API에 비용을 지불할 의향이 있음을 증명한다.

### MVP 성공 기준

- [ ] 출시 후 3개월 내 1,000개 개발자 계정 등록

- [ ] 6개월 내 유료 구독자 50명
- [ ] 6개월 내 MRR $15K

- [ ] 모든 MVP 엔드포인트의 평균 응답 시간(p50) 50ms 미만

### MVP User Journeys

#### Journey 1: 개발자가 CalcEngine을 발견하고 통합

1. 개발자가 "math expression evaluation API"로 검색하여 CalcEngine 문서를 발견.
2. "Get API Key" 클릭 후 한 페이지 가입 폼(이메일, 비밀번호, 회사명 선택) 완료.
3. 확인 페이지와 환영 이메일에서 즉시 API 키 수령.
4. 문서에서 cURL 예제를 복사해 터미널에서 실행: `curl -X POST https://api.calcengine.io/v1/evaluate -H "Authorization: Bearer {key}" -d '{"expression": "sin(pi/4) * 2 + sqrt(16)"}'`
5. JSON 응답 수신: `{"result": 5.414213562373095, "expression": "sin(pi/4) * 2 + sqrt(16)", "precision": "double"}`
6. 문서 사이트의 Python 코드 예제를 복사해 애플리케이션에 붙여 넣고 표현식 문자열을 사용자 입력으로 교체.
7. 애플리케이션 가동. 개발자가 CalcEngine 대시보드에서 사용량 모니터링.

**Outcome**: 발견부터 동작 통합까지 15분 미만.
**Limitation vs Full Vision**: SDK 없음(raw HTTP 호출), 단계별 풀이 없음, 감사 로그 없음.

#### Journey 2: EdTech 회사의 학생용 CalcEngine 평가

1. EdTech 제품 매니저가 개발자에게 숙제 채점 기능용 CalcEngine 평가 요청.
2. 개발자가 무료 등급에 가입 후 일반적인 학생 계산 20개(2차 방정식 근의 공식, 삼각 항등식, 기본 통계)를 API 샌드박스에서 시험.
3. 알려진 정답과 결과를 비교 — 모두 일치.
4. CalcEngine을 숙제 채점기에 통합. 학생이 수학식을 입력하면 앱이 CalcEngine으로 보내고 결과를 정답과 비교.
5. 무료 등급으로 초기 교실 파일럿(500명, 월 ~8,000 호출) 운영. 전체 학구로 확장 시 Starter 플랜으로 업그레이드.

**Outcome**: 수학 파서를 만들지 않고 숙제 채점 기능 출시.
**Limitation vs Full Vision**: 학생용 단계별 풀이 없음, 복소수 지원 없음, 고급 강좌용 미적분 없음.

### MVP 제약 및 가정

- **가정**: 개발자가 수학 연산에 로컬 라이브러리보다 호스팅 API를 선호한다. **Risk if wrong**: 정확한 계산에도 불구하고 낮은 채택. **완화**: 무료 등급으로 낮은 진입 장벽 검증, API 모델 실패 시 오픈소스 라이브러리 모델로 피벗.
- **가정**: 표현식 평가(문자열 입력, 결과 출력)가 최고 가치 기능. **Risk if wrong**: 개발자가 실제로는 개별 함수 엔드포인트를 더 원할 수 있음. **완화**: MVP에 표현식 평가와 개별 함수 엔드포인트 모두 포함, 사용 데이터로 선호 파악.
- **가정**: MVP 사용자에게 IEEE 754 배정도면 충분. **Risk if wrong**: 금융/과학 초기 채택자가 즉시 더 높은 정밀도 요구. **완화**: 임의 정밀도는 Phase 2 우선순위이며 신호가 강하면 가속화 가능.
- **가정**: 월 10,000 무료 호출은 제품 평가에는 충분하지만 유료 전환을 유도할 만큼 낮다. **Risk if wrong**: 무료 등급이 너무 관대(전환 없음)하거나 너무 제한적(평가 전 이탈). **완화**: 2개월 시점 전환 데이터에 따라 조정.
- **수용된 제한**: MVP에 클라이언트 SDK 없음. 개발자는 raw HTTP 호출 필요. 마찰이 늘지만 product-market fit 검증 전에 여러 언어 SDK 구축/유지는 비용 큼.
- **수용된 제한**: 단일 리전 배포(US-East-1). 유럽/아시아 사용자 지연이 더 높음. 계산 페이로드가 작아 대역폭 민감도가 낮으므로 MVP에서는 허용.

### MVP Definition of Done

- [ ] 모든 13개 "Must Have" 기능 구현·테스트·배포 완료
- [ ] 모든 MVP 함수를 다루는 500+ 수학 테스트 케이스의 검증 스위트 통과
- [ ] 엣지 케이스의 우아한 처리: 0 나누기, 오버플로, 언더플로, 잘못된 표현식, 도메인 오류(예: log(-1))
- [ ] 공개 출시 전 2주 burn-in 기간 동안 99.9% 가동률 입증
- [ ] burn-in 기간 동안 p50 50ms 미만, p99 200ms 미만
- [ ] 엔드포인트 레퍼런스, 코드 예제(Python, JavaScript, cURL), 인터랙티브 샌드박스가 있는 문서 포털 가동
- [ ] 청구 통합 동작: 무료 등급 강제, 유료 등급 구매 가능, 사용량 정확 추적
- [ ] OpenAPI 3.x 사양 게시 및 다운로드 가능
- [ ] 보안 검토 완료: API 키 인증, 레이트 리밋, 입력 검증, 인젝션 취약점 없음
- [ ] 부하 테스트 완료: API가 동시 요청 1,000개 처리 시 성능 저하 없음
- [ ] 이해관계자 데모 완료 및 사인오프 수령

### External Dependencies

- **Stripe** - 결제 처리/구독 관리 - 사용 가능, API 잘 문서화됨
- **Auth0 또는 AWS Cognito** - 개발자 인증 - 사용 가능, 1개월 차에 평가
- **도메인 등록기관** - calcengine.io(또는 유사) - 문서 사이트 공개 전 확보 필요
- **클라우드 공급자(AWS)** - 컴퓨팅, API Gateway, 데이터베이스 - 사용 가능, 별도 승인 불필요
- **SSL 인증서 공급자** - API/문서 사이트의 TLS - AWS Certificate Manager로 사용 가능
