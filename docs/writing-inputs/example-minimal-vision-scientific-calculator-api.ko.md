# 비전: CalcEngine 과학 계산기 API

## Executive Summary

CalcEngine은 개발자가 수학 표현식을 문자열로 보내면 정확한 결과를 돌려받는 REST API입니다. 각 팀이 자체적으로 수학 파서와 삼각 함수 구현을 만드는 대신, 이 API를 호출하기만 하면 됩니다. 무료 체험을 통해 사용자 유입을 늘리고, 사용량에 따른 유료 플랜을 제공하는 구독형 서비스로 판매합니다.

## 범위(IN) 기능 (MVP)

- 표현식 평가: `"2 * sin(pi/4) + sqrt(16)"`과 같은 문자열을 받아 숫자 결과를 반환
- 기본 산술: 더하기, 빼기, 곱하기, 나누기, 거듭제곱, 제곱근, 모듈로, 절대값, 내림, 올림, 반올림
- 삼각 함수: sin, cos, tan, asin, acos, atan, atan2 (도/라디안 모드)
- 로그: 상용로그, 자연로그, 임의 밑의 로그, 지수 함수
- 기본 통계: 평균, 중앙값, 최빈값, 표준편차, 분산, 최소/최대, 합, 백분위수 (배열 입력)
- 수학 상수: pi, e, phi, sqrt(2)
- 조합론: 팩토리얼, 순열(nPr), 조합(nCr)
- 오류 처리: 0 나눗셈, 도메인 오류(음수의 로그), 오버플로, 잘못된 표현식에 대한 명확한 오류 코드
- API 키 인증, 무료 플랜(월 10K 호출)과 유료 플랜
- 인터랙티브 샌드박스와 코드 예시를 갖춘 API 문서 포털

## 명시적으로 범위에서 제외(OUT) (MVP)

- 임의 정밀도 산술 (Phase 2)
- 행렬과 선형 대수 (Phase 2)
- 미적분 — 도함수, 적분 (Phase 2)
- 금융 수학 — 분할 상환, NPV, IRR (Phase 2)
- Python/JS/Java용 클라이언트 SDK (Phase 2 — MVP에서는 raw HTTP면 충분)
- 단계별 풀이 (Phase 3)
- 단위 변환과 물리 상수 (Phase 3)
- 배치 처리/비동기 웹훅 (Phase 3)
- 기호 계산 (Phase 3)
- 온프레미스 배포 (Phase 3 이후)

## 대상 사용자

- 제품에 수학 기능이 필요하지만 직접 구축/유지보수하기를 원치 않는 애플리케이션 개발자
- 학생용 도구의 계산기 백엔드가 필요한 EdTech 기업
- 감사 가능한 계산이 필요한 FinTech 스타트업 (유료 플랜, Phase 2 중점)

## 핵심 성공 지표

- 3개월 내 1,000개 개발자 계정 등록
- 6개월 내 50개 유료 구독자
- API 가동률 99.9%
- p50 응답 시간 50ms 미만
- 결정적(Critical) 정확도 버그(잘못된 계산 결과) 0건

## 미해결 질문

- 결과를 문자열로(정밀도 보존) 반환할지, JSON 숫자로 반환할지?
- 암시적 곱셈(`2pi`가 `2 * pi`)을 지원할지?
