Review UI — ten ways to review an agent's work

Each variation tests one hypothesis about how a human best reads, annotates, answers, and decides on an artifact an AI agent wrote. Same content everywhere (the to-do app requirements at r1, four threads, four questions with explainers, FR2 in suggest-edit mode) so only the experience differs. Every one keeps the terminal complete: comments become feedback-NNN.md, answers answers-NNN.json, decisions converge on the same gate.
