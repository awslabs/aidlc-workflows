## AskUserQuestion Extension Credit

This extension was created by [ghoseb](https://github.com/ghoseb/pi-askuserquestion/) and is not licensed. You can find the source code and contribute to the project on GitHub.

This extension is designed to ask the user a question and provide options for them to choose from. It can be used in various scenarios where user input is required, such as confirming an action or gathering information. It was included in the Pi extension library to provide a convenient way for developers to interact with AIDLC workflows.
