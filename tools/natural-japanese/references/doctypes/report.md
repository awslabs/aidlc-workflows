# 調査レポート:数字が意思決定にどう関わるかまで書く

## この文書が答える問い

調査レポートが答える問いは、何が起きていて、次に何をすべきかである。データを集めて記述しただけでは、調査は終わっていない。読み手が知りたいのは数字そのものより、その数字が意思決定にどう関わるかで、書き手がそこまで書かなければ、読み手は自分でグラフを見て解釈し直すことになる。良いレポートは、冒頭の数行を読んだだけで次にどうすればよいかまで判断できる。

## 必須要素

次の6つを、この順に並べる。

1. 調査の目的(誰が何を決めるための調査か)
2. 冒頭のまとめ(主メッセージと論点)
3. 調査結果
4. 次にすべきことの提案
5. データの限界
6. 方法(第三者が同じ手順をたどれる程度)

このうち方法とデータの限界は、短くてもよいので省かない。方法がなければ読み手は数字の確かさを確かめられず、限界がなければ数字だけが独り歩きする。

## 構成

組み立ては、ピラミッドの形にする。読み手が冒頭だけで判断でき、根拠を確かめたい人だけが本文に進めるようにするためだ。冒頭と提案は流し読みでも分かるように箇条書きや表にし、本文の節はじっくり読めるように、結論の一文、表、理由を書いた短い地の文で組む。

- 冒頭の一行目に、調査の目的を一文で書く(「7月の部会で解約対策を決めるため、4〜6月の解約を調べた」)。節にはしない
- 続けて、一文の主メッセージを書く。依頼に「決めたいこと」が含まれるなら、主メッセージでは、どう決めればよいかを書く(「〜を確かめてから、〜を決めるのがよい」)。所見だけで終わらせない。続けて、主メッセージを支える論点を2〜4つ、番号つきの箇条書きで並べる。各項目は、結論の一文と主な数値にする。論点どうしは重ならないように分ける
- 冒頭には、定義や方法の節を置かない。定義は、最初にその数字が出てくる表のそばに一行で書き、方法の節は末尾に回す
- 本文の節は、冒頭の論点に一つずつ対応させ、見出しにはその論点を結論の文で書く。見出しだけを順に読むと、冒頭の論点がたどれるようにする。各節は、頭に結論を書き、続けて根拠(表や数字)を示す
- セグメント、仮説、選択肢のように並べて比べるものは、表にしてよい。SKILL.md 原則3の「箇条書きは本当に独立して並ぶときだけ」より、レポートではこちらを優先する。読み手が知りたいのは比べた結果で、地の文に書くと比べにくくなる
- 事実(何が起きたか)、解釈(だから何が言えるか)、打ち手や検証(次に何をするか)を分けて書く。どの文がどれに当たるかが、読み手に分かるようにする
- 提案は、「決める前にできる検証」と「決める場で選ぶ選択肢」に分ける。
- 選択肢は表か箇条書きにし、それぞれに、支える数字、確かめること、選ぶ条件(「検証で〜なら A、〜なら B」)を添える。選択肢は、素材にある関係者の案、検証の結果で決まる案、何もしない(待つ)案から作り、素材にない施策や数字(期間、費用、効果の見込みなど)は足さない。書き手として推す案があれば、「〜と考える」と書いて一つまでにする。依頼に決めたいことがない定点観測のレポートでは、選択肢は作らない
- データの限界と方法は、提案の後に置く。ただし、誤読されやすい数字の注記は、その数字のすぐそばに置く(品質基準)
- 集計クエリや除外条件の内訳のような技術的な詳細は、末尾か付録に回す

続編の調査なら、冒頭のまとめの直後に、前回の調査との関係を一段落で書く。何が変わって再調査したのか、前回の結論のどこを引き継ぎ、どこを覆すのかを先に示しておくと、本文の位置づけが分かる。過去の号に誤りがあれば、末尾でなく冒頭の近くで訂正する。読み手が結論を読む前に、訂正を知っている必要があるためだ。

## 品質基準

- 冒頭のまとめを読んだ人が、次にどうすればよいかまで分かる。数値を並べただけで、その意味が本文の奥にしか書かれていないなら、まとめになっていない
- 事実と考察を書き分けている。「〜だった(出典: アクセス解析、7月集計)」という事実と、「〜と考えられる」という書き手の考察を、地の文の中でも区別できるように書く。自社のデータなのか、他社の事例からの類推なのかも混ぜない
- 誤読されやすい数字には、書き手が先に注記している。合計や平均が一つの外れ値に引っ張られている、母数が小さくて比率が安定しない、季節の影響で単純に比べられない、といった点は、読み手が気づく前に書く。注記は末尾にまとめず、その数字のすぐそばに置く
- 数字の意味を言い換えている。「継続率は4%だった」で終わらせず、「96%は継続しなかった」まで書くと、読み手が計算しなくても意味が分かる
- 母集団の定義が、最初にその数字が出てくる表のそばにある。「訪問数」がボットを含むすべてのアクセスなのか、除いたあとの訪問なのか、集計期間はいつからいつまでかを書く。定義が調査ごとに変わると、前回との比較が成り立たない
- セグメントごとに濃淡がある。すべてのセグメントを同じ文型・同じ分量で並べず、変化のあったセグメントは厚く、変化のないセグメントは「特に変化なし」の一言で済ませる

## AI がやりがちな失敗

もっとも目立つのは、データを記述したところで終わり、次にすべきことまで書かない失敗である。「訪問数は前月比で減少した」で文章が終わり、だから何をすべきかがどこにも書かれていない。

逆に、根拠が支える範囲を超えた提案を書くこともある。一部の数字だけを見て施策の優先順位まで決めてしまうと、注記で書いた偏りと結論が食い違う。

ほかに、次の失敗がよく起きる。

- セグメント別の記述を「Aチャネルは〜だった。Bチャネルは〜だった。Cチャネルは〜だった。」と同じ文型で並べ、どこに重要な差があるのかを見えなくする
- 注意書きを末尾にまとめ、外れ値1件が合計を押し上げていたことを、最後まで読んだ人にしか伝えない
- 母集団の定義を書かずに前回と比べる。定義が前回と同じかを確かめずに増減を書くと、集計方法の違いを比べているだけになりかねない

## 特に関わる原則(SKILL.md §2)

- 原則1(結論を先に):冒頭のまとめが、数値つきの結論そのものになっている
- 原則12(結び):事実の記述で終わらせず、次にすべきことを書く。ただし根拠の範囲を超えない
- 原則11(事実と意見):出典と、一次か二次かの区別、考察の部分を明示する
- 原則10(確信の度合い):データの限界と、過去の誤りの訂正を隠さずに書く
- 原則7(濃淡):セグメントごとに書く分量を変える

## 雛形

架空の EC サイト「そらマルシェ」の流入経路を調べた月次レポートの、冒頭と提案の部分を例にする。

```
# そらマルシェ 流入経路調査(2026年6月分)

7月の販促会議で SNS 導線への予算配分を決めるため、6月の流入経路を調べた。

訂正: 前号(5月分)で「検索流入は横ばい」と書いたが、集計対象に
社内アクセスが混入しておりデータの誤りだった。除外後は前月比
5%減で、今号の「2カ月連続の減少」は訂正後の数値にもとづく。

SNS 導線への予算配分は、上位1商品を除いた7月の購入率を見てから決めるのがよい。

1. 検索流入が2カ月続けて減った(71,200件、前月比 -8%)。総訪問数の減少(-3%)の主因である
2. SNS経由の購入率は4.6%で、サイト平均(2.0%)の2.3倍に見える
3. ただし購入の41%が上位1商品(季節限定の虫よけスプレー)で、除くと2.1%と平均並みになる

(本文:論点ごとの節。見出しは論点の結論の文、頭に結論、続けて表と理由)

## 次にすべきこと

会議の前にできる検証
- 上位1商品を除いた SNS 経由の購入率を、7月前半の分で出す

会議で選ぶ選択肢
| 選択肢 | 支える数字 | 選ぶ条件 |
|---|---|---|
| SNS 導線の予算を増やす | 購入率 4.6%(平均の2.3倍) | 1商品を除いても平均を上回るとき |
| 今の配分のまま、検索流入の減少を先に調べる | 検索流入 2カ月連続の減少 | 1商品を除くと平均並みのとき |

## データの限界 / 方法
(末尾に置く)
```

## 記述で終わる文と、次にすべきことまで書く文

次の調査結果をもとに、レポートの本文を書く場合を考える。

素材:6月の数字。総訪問数 128,400(前月比 -3%)。検索流入 71,200(前月比 -8%、2カ月連続の減少)。SNS経由の購入率 4.6%(サイト平均 2.0%)。SNS経由の購入の41%が上位1商品で、この商品を除くと購入率は2.1%。チームの考え:SNS導線に力を入れるかは、この1商品を除いた数字を見てから決めたい。

記述で終わる文:

> 6月の総訪問数は128,400件で、前月から3%減少した。検索流入は71,200件で前月比8%減、SNS経由の購入率は4.6%だった。

次にすべきことまで書く文:

> 6月の総訪問数は128,400件で、前月比3%減だった。検索流入は2カ月続けて減り、前月比8%減の71,200件だった。前月比から逆算すると、検索流入の減少は約6,200件で、総訪問数の減少(約4,000件)より大きい。ほかの経路からの訪問は増えていることになる。SNS経由の購入率は4.6%でサイト平均の2.3倍だが、購入の41%を占める上位1商品を除くと2.1%で、平均(2.0%)とほぼ同じになる。チームとしては、SNS導線に力を入れるかどうかを、この1商品を除いた数字を見てから決めたい考えである。

記述で終わる文は、数字を並べただけで、読み手は何をすべきかを自分で考えることになる。もう一方の文は、素材にある数字だけを使い、検索流入の減少が総訪問数の減少を上回っていることを計算で示し、SNS経由の高い購入率が1商品に支えられていることを先に書いたうえで、チームの考えを、意向のまま(「決めたい考えである」)書いている。計算で出した数字(約6,200件、約4,000件)は素材の数字から導いたもので、素材にない数字や理由は足していない。
